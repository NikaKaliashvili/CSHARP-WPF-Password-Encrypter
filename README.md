## Password Encrypter
A desktop password encryption and decryption tool built with C# and WPF.

The application provides a simple graphical interface for encrypting and decrypting text using a custom encryption algorithm developed as a programming and cryptography learning project.

## Features
##### Encrypt text using a custom encryption algorithm
##### Decrypt previously encrypted text
##### Simple WPF graphical user interface

## Technologies
#### C#
#### WPF
#### XAML
#### .NET

## Running the Project
###### Clone the repository:
#### ``git clone https://github.com/NikaKaliashvili/CSHARP-WPF-Password-Encrypter.git``
#### Open PasswordEncrypter.sln in Visual Studio.
#### Build the solution.
#### Run the application.
